How it works

No drama. Just a receipt for every choice.

01

Scan locally

Eagle inspects everyday cleanup, maintenance, project clutter, installers, and disk usage on your Mac. File names and contents never leave the device.

02

Review clearly

Results are grouped into suggested and optional actions. Advanced command output stays tucked away unless you open it.

03

Confirm deliberately

Nothing destructive runs from a scan. You choose what goes, confirm the action, then get a local receipt with what changed.

Safety

The app is allowed to be useful. It is not allowed to be sneaky.

Eagle treats maintenance as a consent workflow, not a background ritual. Your files matter more than a dramatic storage number.

01

Nothing uploads

Scans run locally. No file contents, names, browser history, documents, or cleanup lists are transmitted.

02

Preview before action

Every destructive path goes through review and confirmation. No silent sweeps, no panic banners.

03

Refuse when unsure

System roots, credentials, iCloud, keychains, messages, and protected app state are skipped by design.

04

Receipts stay local

Each operation records what changed, what failed, and what was protected so you can reason about it afterward.

Questions

Straight answers, no tiny print.

Is Eagle free?

Yes. The intended product model is free download with optional support. No license activation is required for v1.

How do I install it?

Open the downloaded DMG, drag Eagle.app to Applications, then open it from Applications. Because this preview is not notarized yet, use right-click Open the first time. If macOS still says damaged, run xattr -dr com.apple.quarantine /Applications/Eagle.app once.

Does it replace the Mole CLI?

No. Eagle is a native Mac app around local Mole workflows. The CLI remains the open-source base and attribution stays visible.

Will it run without Full Disk Access?

Yes, but deeper caches and app containers may be skipped. The app should explain what permission changes before asking for it.
